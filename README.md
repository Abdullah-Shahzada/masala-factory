# Masala Factory Business Management System

A professional, modern, responsive B2B business management application built for masala manufacturing factories and spice B2B supply businesses across multiple factory branches in Pakistan.

## Business Features
* **Multi-Branch Operations**: Branch switching (Main Lahore Factory, Karachi Hub, Faisalabad Unit).
* **Sales Bills**: Dynamic line item calculation, manual bill numbers (`B-1547`), partial/paid status tracking.
* **Payments Received**: Customer payment collection with automatic bill balance updating & payment proof previews.
* **Payment Schedules**: Dual tracking for *Payments to Receive* (receivables) and *Payments to Pay* (payables).
* **Purchases**: Separate supplier purchase bills management.
* **Expenses**: Dedicated factory operational expense tracking across 11 key categories.
* **Party Ledgers**: Deep party audit trail with detailed itemized transaction history and PDF statement export.
* **Analytical Reports**: Sales trends, receivables aging, expense breakdown, branch performance comparison.
* **Settings**: Business branding, branch management, product & rate master catalog.

## Tech Stack
* **Frontend Framework**: React 18 / 19 with TypeScript
* **Build Tool**: Vite
* **Styling**: Tailwind CSS, Lucide Icons
* **Routing**: React Router v6 / v7
* **Charts**: Recharts
* **PDF / Document Export**: Client-side PDF rendering & HTML print engine

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run build verification
npm run build
```
